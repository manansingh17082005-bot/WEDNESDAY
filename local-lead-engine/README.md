# WEDNESDAY Local Lead Hunter

A local Python service for WEDNESDAY's Lead Generation page. It uses Python's standard library and DuckDuckGo's publicly accessible HTML search page. No paid API, API key, database or third-party Python package is required.

## Requirements
- Windows 10 or 11
- Python 3.10+
- Internet connection

## Start
1. Download or update the WEDNESDAY repository.
2. Open the local-lead-engine folder.
3. Double-click start-wednesday-lead-engine.bat.
4. Keep its terminal window open.
5. Open the WEDNESDAY website and run a search.

Health check: http://127.0.0.1:8765/health

## Qualification
A = explicit buyer request. B = visible business-problem evidence. Scores are research priorities, not hiring probabilities. Review source pages and verify contacts manually. The tool never sends outreach.

## Limitations
Public search engines may rate-limit or block automated requests. Results are not guaranteed or unlimited. Contact details are extracted from public pages and may be incomplete or inaccurate. The local service runs only while it is open on your computer. It does not bypass logins, CAPTCHAs or access restrictions. Follow source-site terms, robots policies and opt-outs.
